# Anivibe для Android — Нативный порт

Полноценный нативный порт приложения **Anivibe** с iOS на платформу **Android**, реализованный на современном стеке **Kotlin + Jetpack Compose + Media3/ExoPlayer + Room + Supabase**.

---

## 📱 Поддерживаемые устройства и форм-факторы

Приложение полностью адаптировано под три типа экранов:
1. **Смартфоны:** Классический мобильный интерфейс с `NavigationBar` внизу экрана, компактная адаптивная сетка (2–3 колонки).
2. **Планшеты:** Широкоэкранный интерфейс с боковым `NavigationRail`, расширенная сетка (4–5 колонок), удобный просмотр описаний и списков серий.
3. **Android TV:** 
   - Полноценная поддержка пульта управления (D-Pad): навигация стрелками, центральная кнопка для подтверждения / паузы, перемотка серий влево/вправо на 10 сек.
   - Визуальный эффект фокуса (`tvFocusable`): активный элемент плавно увеличивается (scale 1.06x) и подсвечивается акцентной рамкой.
   - Поддержка запуска из главного меню Android TV (`LEANBACK_LAUNCHER`).

## 🛠 Технологический стек

| Компонент | Технология | Описание |

## 🔄 Миграции и совместимость с базой данных Supabase

Приложение полностью повторяет структуру данных и правила сервера из `supabase/migrations/`:

* **`library_entries`**:
  * Статусы: `watching` («Смотрю»), `completed` («Просмотрено»), `planned` («Запланировано»), `onHold` («Отложено»), а также новый статус **`dropped` («Брошено»)** из обновления `20261015000000_bugfix_library_status.sql`.
  * Флаг `is_favorite` («Избранное»).
  * Поле `last_episode` (последняя открытая серия).
  * Мягкое удаление `is_deleted` для корректного слияния данных между устройствами.
* **`watch_progress`**:
  * Композитный первичный ключ `(anime_id, episode, source_key)`.
  * Точное сохранение позиции и длительности в секундах.
* **`watch_history`**:
  * UUID записей, время просмотра `watched_at` и метка удаления `deleted_at` (tombstone).
* **`account_collections`**:
  * Пользовательские папки на главной с эмодзи и порядком отображения.

## 🎬 Источники видео и озвучки

1. **Kodik API (`kodik-api.com`):**
   * Поиск материалов по `shikimori_id` и названиям.
   * Десятки вариантов студий озвучки (Anilibria, AniDUB, SHIZA Project, Студийная Банда и др.).
   * **Нативный декодер прямых HLS-потоков:** модуль `KodikStreamResolver` извлекает прямые потоки через обращение к `/ftor`, применяет алгоритм расшифровки (сдвиг Цезаря + Base64) и передаёт потоки 360p/480p/720p/1080p в нативный `ExoPlayer`.
   * **Резервный веб-плеер (`KodikWebViewPlayer`):** если прямой поток недоступен, открывается официальный плеер Kodik.
2. **Anilibria (AniLiberty):**
   * Официальный публичный API с автоматическим отказоустойчивым переключением между тремя зеркалами: `anilibria.top`, `api.anilibria.app`, `aniliberty.top`.
   * Прямое воспроизведение HLS-серий.
3. **AniList GraphQL:**
   * Каталог, тренды, сезоны, поиск с расширенными фильтрами (жанры, формат, статус, год).
4. **Shikimori:**
   * Русские локализованные названия, синонимы, транслитерация русскоязычных поисковых запросов и очистка описаний от BBCode.

## 🚀 Как открыть и собрать проект

1. Откройте **Android Studio** (Hedgehog, Iguana, Jellyfish, Koala или новее).
2. Выберите **File → Open...** и укажите папку:
   ```text
   C:\Users\ninaa\Downloads\Anivibe\android
   ```
3. Дождитесь автоматической синхронизации Gradle (Gradle Sync).
4. Запустите на устройстве или эмуляторе (Phone, Tablet или Android TV):
   - Нажмите зелёную кнопку **Run (Shift + F10)**.
5. Для сборки релизного/отладочного APK через терминал:
   ```bash
   cd C:\Users\ninaa\Downloads\Anivibe\android
   .\gradlew assembleDebug
   ```
   Собранный файл появится в `android/app/build/outputs/apk/debug/app-debug.apk`.
