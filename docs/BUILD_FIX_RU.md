# Исправление сборки общего просмотра

В присланном логе GitHub Actions сборка Debug Simulator завершается с exit code 65. Все 14 сообщений компилятора относятся к 7 обработчикам в `Anivibe/Features/Community/WatchRoomViews.swift`.

Внутри `catch` Swift автоматически объявляет неизменяемую локальную `error: Error`. Выражение `error = CommunityStore.message(error)` пыталось присвоить ей строку, а не обновить одноимённое поле `@State`. Исправлено во всех семи местах:

```swift
} catch {
    self.error = CommunityStore.message(error)
}
```

## Как обновить

- Для самой ошибки достаточно заменить **один** файл `Anivibe/Features/Community/WatchRoomViews.swift` в своём проекте на файл из этого архива.
- Либо применить `git apply --check build-fix.patch`, затем `git apply build-fix.patch` поверх предыдущей поставки `Anivibe-social.zip`. Не применять эту маленькую правку повторно поверх уже исправленного файла.
- Для постоянной защиты также добавить `scripts/test_swift_error_shadowing.py` и обновлённый `.github/workflows/ios.yml`. Полный архив включает оба файла.
- Сделать commit/push и дождаться нового результата GitHub Actions. Старый упавший запуск сам по себе не проверяет новые исходники.

`community-update.patch` в полном архиве тоже обновлён, но он рассчитан на **более старую базу** `Anivibe-improved.zip`. Не путать его с `build-fix.patch`, предназначенным для уже установленной социальной версии.

## База данных

SQL и все миграции сохранены побайтово. Эта ошибка не требует новых миграций Supabase. Если три миграции социальной системы уже применены, повторять их из-за этой правки не нужно.
