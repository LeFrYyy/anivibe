# Формат манифеста собственного источника (ManifestProvider)

`ManifestProvider` — реально работающий адаптер для видео, **права на распространение которых есть у вас**
(собственный контент, контент по лицензии, ваш медиасервер/CDN). Приложение загружает JSON-манифест по
адресу из `ANIVIBE_MANIFEST_URL` и сопоставляет записи с тайтлами каталога.

Пример: [`stream-manifest.example.json`](stream-manifest.example.json).

## Поля

| Поле | Тип | Описание |
|---|---|---|
| `version` | число | Всегда `1`. Другие версии отклоняются с понятной ошибкой. |
| `providerName` | строка, опц. | Имя источника в интерфейсе плеера. |
| `titles[].id` | строка | Ваш идентификатор тайтла. |
| `titles[].anilistId` | число или `null` | ID тайтла в AniList — самое надёжное сопоставление. Если указан, запись сопоставляется **только** с этим ID. |
| `titles[].titles` | массив строк | Названия для сопоставления, если `anilistId` не указан (нормализация регистра, диакритики, пунктуации; номер сезона в названии должен совпасть). |
| `episodes[].season` | число или `null` | `null` — сквозная нумерация. Каталог AniList хранит каждый сезон отдельным тайтлом, поэтому обычно `null` или `1`. |
| `episodes[].number` | число | Номер серии (с 1). |
| `episodes[].title` | строка или `null` | Название серии. |
| `episodes[].url` | строка | **Только `https`**. `.m3u8` (HLS) или `.mp4`/`.m4v`/`.mov`. |
| `episodes[].expiresAt` | ISO 8601 или `null` | Срок действия временной ссылки. Просроченные ссылки не воспроизводятся, а манифест не кэшируется дольше ближайшего срока. |

## Как проверяется доступность

Перед тем как показать источник «доступным», приложение:

1. Загружает манифест (кэш в памяти до 10 минут, но не дольше ближайшего `expiresAt`).
2. Находит тайтл (по `anilistId`, затем по названиям) и серию.
3. Для HLS — скачивает плейлист и проверяет, что это `#EXTM3U`; извлекает объявленные аудиодорожки и субтитры.
   Для MP4 — делает `HEAD`-запрос.

## Требования к серверу

- HTTPS с валидным сертификатом (ATS не ослабляется).
- Для HLS — корректный `Content-Type` (`application/vnd.apple.mpegurl`) и кодеки, поддерживаемые iOS (H.264/HEVC, AAC).
- Видео с DRM (FairPlay) этим адаптером не поддерживается.
- Если нужна авторизация, не кладите секреты в URL манифеста — используйте подписанные короткоживущие ссылки,
  которые выдаёт ваш сервер, и поле `expiresAt`.
