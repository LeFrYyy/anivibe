# Объединённая версия исправлений сборки

## Включено

- Исправлен конфликт `error` в BackgroundSettings: используется `self.error`.
- Чтение accentHex и применение темы выполняются после инициализации всех AppSettings.
- Поиск каталога захватывает неизменяемую копию запроса.
- URL проекта и публичный publishable key сохранены в Config/Supabase.xcconfig; Secrets.xcconfig и GitHub secrets могут переопределить их.
- Supabase Auth не отправляет API key в пользовательском Bearer; пользовательский access token используется там, где он требуется.
- Ошибка декодирования пользовательского фона отображается вместо молчаливого прекращения операции.
- Неудачная загрузка рекомендаций не блокирует повторную попытку; устаревшие результаты запроса не заменяют новые.
- OAuth browser session освобождается и при ошибке.

## Что фактически проверено для этой версии

- Статические проверки структуры проекта, plist/JSON и известных исправлений — успешно.
- 8 Python-тестов генерации CI-конфигурации — успешно.
- YAML workflow и синтаксис 9 shell-шагов — успешно.
- Целостность полного ZIP — проверяется при упаковке.

Swift в среде этой правки отсутствует. Swift regression tests добавлены/обновлены, но не запускались. Полная компиляция iOS, запуск на iPhone, Google-вход, SMTP и облачная синхронизация после этих правок НЕ проверены. Предыдущие отчёты о тестах относятся к предыдущим версиям, а не к текущему архиву.

## Что проверит следующий GitHub Actions запуск

1. Структуру и статические проверки.
2. Python-тесты CI-конфигурации.
3. swift test для AnivibeCore.
4. Компиляцию Debug для iOS Simulator (без запуска приложения).
5. Компиляцию Release для iPhone.
6. Структуру unsigned IPA.

Workflow запускается при push в main; логи тестов и сборок сохраняются в artifacts. Используется выбранный по умолчанию Xcode образа macos-15, а не автоматический выбор максимального имени Xcode*.app. Этот образ обновляется GitHub: версия Xcode выводится в лог.

Зелёная сборка не гарантирует отсутствие ошибок во время использования. После установки проверьте регистрацию/Google, синхронизацию двух аккаунтов, библиотеку, каталог, плеер и фон. Три миграции и конфигурация Auth в Supabase по-прежнему выполняются отдельно.

## Обновление Windows-репозитория

Распакуйте архив в отдельную папку и запустите UPDATE_WINDOWS.cmd из неё. По умолчанию скрипт копирует файлы в %USERPROFILE%\Downloads\Anivibe; другой репозиторий можно передать первым аргументом. Перед заменой сохраните дополнительные локальные изменения. Скрипт запрашивает подтверждение, сохраняет .git и Config/Secrets.xcconfig, не удаляет старые файлы и не выполняет commit/push автоматически. Сам скрипт Windows в Linux не выполнялся.
