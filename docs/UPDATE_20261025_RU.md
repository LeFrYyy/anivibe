# Anivibe v4 — удержание 2×, плоские папки, исправления

Основа: присланный `Anivibe-bugfix-v3.zip`. Это обновление исходников, не готовый IPA. Новых SQL-миграций, зависимостей и изменений серверных правил нет.

## 1. Что сделано по каждой задаче

### Задача 1 — удержание для временной скорости 2×

- На поверхности **нативного AVPlayer** добавлен `UILongPressGestureRecognizer`: порог 400 мс, допустимое перемещение до распознавания — 12 pt, один палец.
- Во время удержания применяется 2×; после отпускания/отмены возвращается выбранная пользователем скорость: 0.5 / 0.75 / 1 / 1.25 / 1.5 / 1.75 / 2×. Значение в настройках и `defaultRate` не перезаписываются ускорением.
- Запуск запрещён при паузе, загрузке, буферизации, перемотке, открытых модальных экранах, countdown следующей серии, активном PiP и совместном просмотре. Проверяется как модель, так и фактическое состояние AVPlayer/currentItem.
- Жест находится на UIView видеослоя, не на контейнере элементов управления. Обычный tap ждёт отказа long press; после распознавания удержания перемещение пальца не вызывает tap или seek. В исходном нативном плеере **не было** double-tap/swipe-перемотки: такие действия не добавлялись и не удалялись.
- Ускорение снимается при паузе/буферизации, seek, смене источника/серии, уходе приложения из active, PiP, исчезновении экрана и демонтаже UIView. Завершение удержания само по себе никогда не возобновляет паузу.
- Успешное начало даёт один лёгкий системный haptic; неудачное удержание — без haptic.
- Сверху по центру — компактная тёмная полупрозрачная капсула «2×» с двумя стрелками. Fade+scale — 180 мс. Во время ускорения controls скрыты, HUD не принимает касания. Пульсация стрелок локальна для HUD; таймеров и обновления видеослоя на каждый кадр нет.
- Reduce Motion отключает пульсацию/scale, Reduce Transparency включает сплошной тёмный фон.

### Задача 2 — папки без градиентов

- В плитках, фоне, открытой папке, backdrop, элементах и кнопках убраны градиенты, материалы/blur и тени. Вместо них — сплошные поверхности и тонкая граница.
- Используется основной акцент приложения, нейтральная палитра и семантический danger только для удаления. Новый `Theme.Folder` собирает основные цвета, радиусы, размеры, отступы и ограничения панели.
- Убрана принудительная dark-схема. Фон, названия, обводки и пустые слоты адаптируются к light/dark.
- Длинные названия плиток допускают две строки; полный текст доступен VoiceOver. Пустые папки сохраняют понятные placeholders и кнопку добавления. Сетка остаётся lazy; логика добавления/удаления/перестановки сохранена.
- Панель ограничена шириной 520 pt, высота сетки зависит от доступной геометрии, не превышает 460 pt. Это защищает обычный landscape-сценарий; крайние Dynamic Type/keyboard-состояния требуют устройства.
- Пустое переименование восстанавливает прежнее имя в поле. Сохранение имени по-прежнему защищено от смены аккаунта.
- Проверка исходников: в блоке папок `HomeView.swift` и `FolderSelectionSheet.swift` нет `Gradient`/`Material`; в блоке папок также нет `.shadow(`. Градиенты **вне папок**, например scrim/timeline плеера, намеренно не менялись.

### Задача 3 — обзор, баги, оптимизации и регрессии

- Просмотрены основные пути плеера, поиска источников, папок, каталоговой пагинации, библиотеки и сетевого транспорта; исправления перечислены ниже. Это не гарантия отсутствия иных ошибок во всём приложении.
- Добавлены 19 XCTest для новой логики Core и 8 проверок подключения/структуры исходников; прежние регрессии сохранены и актуализированы.
- Обновлён CI: новые source-checks выполняются до Core-тестов и iOS-сборок.
- Удалены только подтверждённые дубли/неиспользуемые альтернативные реализации. Рабочий `WebPlayerView` сохранён как Kodik fallback.

## 2. Баги: описание / причина / исправление

| Проблема | Причина | Исправление |
| --- | --- | --- |
| Нельзя заново запустить закончившуюся серию кнопкой Play | `play()` вызывался в позиции конца файла | При Play у конца выполняется seek к 0, countdown отменяется |
| Старый поток мог продолжать играть или прислать ready во время нового поиска | Повторный поиск не снимал observers и не отключал старый item | Сохранение позиции, pause, cleanup observers и удаление item до поиска; сохранено намерение pause/play |
| Старт ожидал самый медленный резервный источник | Реестр возвращал только полный массив после всех проверок | Поток прогрессивных результатов и ранний выбор только гарантированно приоритетного источника |
| Разовый обрыв/502–504 сразу превращался в ошибку запроса | В стандартном транспорте не было ограниченных повторов для GET/HEAD | До двух повторов с backoff; небезопасные записи, 4xx, offline и timeout не повторяются |
| Папки плохо читались в light mode | Белые слоты/текст и принудительная dark-схема модальной папки | Адаптивная Theme-палитра и удаление локального принуждения к dark |
| Панель папки была слишком высокой/широкой в landscape | Фиксированный предел высоты без учёта экрана, без width cap | Ограничение по GeometryReader и максимальная ширина |
| После пустого rename поле выглядело пустым, хотя модель отвергала переименование | UI не возвращал старое имя после отказа модели | Единый `commitName()` восстанавливает прежнее имя |
| Сохранённая произвольная/невалидная скорость могла попасть в AVPlayer | Из UserDefaults принималось любое положительное значение | Чтение и установка только поддерживаемых скоростей, иначе 1× |
| Триггер пагинации зависел от полного совпадения Anime | `firstIndex(of:)` сравнивал всю модель | Поиск по стабильному `id`, без сравнения всех метаданных |
| Предупреждения concurrency при чистой Core-сборке | Formatter захватывался closure; test transport захватывал XCTestCase | Общий codec под NSLock и статический test router; итоговая чистая сборка без предупреждений |
| Битая строка загрузки | Повреждённый текст ресурса в SwiftUI | Восстановлена строка «Загружаем видео и восстанавливаем позицию…» |

Дополнительно новые утилиты защищены от собственных крайних случаев: подпись скорости не преобразует огромный Float в Int; некорректный/отрицательный/non-finite и HTTP-date `Retry-After` не запускает преждевременный retry. Доступ к кэшированным форматтерам сериализован.

## 3. Оптимизации и эффект

- **Параллельный поиск без ожидания медленного backup.** В тесте быстрый приоритетный провайдер становится доступен до завершения резервного с задержкой 1.5 с; полный список по-прежнему приходит в sheet. Порядок Kodik/реальные/тестовые сохранён. Если более приоритетный провайдер ещё не ответил, ждём его — быстрый тестовый поток не подменяет реальную серию.
- **Форматтеры дат создаются один раз.** Два экземпляра (fractional и legacy) переиспользуются вместо пересоздания при каждом encoder/decoder; старые даты читаются, дробные секунды сохраняются. Это уменьшение аллокаций, не измеренный FPS-бенчмарк.
- **Счётчики библиотеки — один проход.** Пять status-чипов и favorites больше не делают шесть отдельных сканирований массива за вычисление UI. История берётся по `count`.
- **Плоские папки.** Убраны повторяющиеся material/gradient/shadow-слои, сохранены LazyVGrid и существующий image pipeline. Ожидаемо меньше compositing; конкретный выигрыш GPU/FPS не измерялся.
- **Локальная анимация HUD.** Нет общего таймера для видеоплеера и бесконечных `.repeatForever`; PhaseAnimator существует только во время отображения ускорения.
- **Ограниченный retry.** Для кратковременных сбоев GET/HEAD default backoff — 0.4 и 0.8 с; максимум три отправки с учётом исходной. Короткий числовой `Retry-After` учитывается, длинный/неразобранный — возвращает исходный ответ без повтора. POST/PATCH/PUT/DELETE автоматически не повторяются.
- **Удаление дублей.** Убраны недостижимые `KodikPlayerScreen`/`NativeVideoPlayer` и два устаревших файла корневого `Features/`; общая подпись скорости вынесена в Core. Корневые дубли не входили в iOS target, их удаление не выдаётся за ускорение приложения.

## 5. Что сомнительно / проверить на устройстве

### Осознанные безопасные решения

- Функция относится к нативному AVPlayer. Внешний embed/web-плеер Kodik не изменён: его DOM, скорость и сохранение прогресса управляются самим провайдером.
- Совместный просмотр и PiP не ускоряются, чтобы не нарушать синхронизацию или системный UX.
- Если пользователь уже выбрал 2×, удержание остаётся допустимым: показываются HUD/haptic, численно скорость не меняется; отпускание оставляет 2×.
- При начавшейся буферизации ускорение снимается; до нового удержания автоматически не включается. Выбранная скорость и пауза сохраняются.
- Двойное касание и свайп-перемотка отсутствовали в исходном нативном плеере; их не изобретали ради задачи.
- HTTP-date `Retry-After` трактуется консервативно: автоматический повтор не выполняется, а не угадывается дата. Нет утверждений о live-доступности API.

### Обязательный smoke-test перед выпуском

1. Собрать Debug для iOS Simulator и Release для iPhone в Xcode/CI; исправить возможные ошибки typecheck/SDK до релиза.
2. На реальном iPhone проверить hold 400 мс и release для всех скоростей, особенно 1.25/1.5/2×; скорость в настройках не должна меняться.
3. Tap, два быстрых tap, движение до/после порога, уход пальца за границу, второй палец, системное прерывание и поворот экрана: ни лишнего seek, ни «залипшего» ускорения.
4. Удержание кнопок, timeline, sheet, pause/loading/buffering: boost не включается. Haptic один и только при принятом hold.
5. HUD не перекрывает реальные субтитры, safe area/вырез и controls в portrait/landscape; проверить верхние субтитры/другие варианты потока. При необходимости скорректировать верхний отступ после просмотра реального контента.
6. Reduce Motion / Reduce Transparency / VoiceOver / крупный Dynamic Type. На слабом устройстве — Instruments/Core Animation: FPS, dropped frames, GPU и memory. Производительность без такого замера не подтверждена.
7. Пауза/запуск в конце серии, смена серии/качества/источника, refresh во время preparing, offline, 503 и закрытие экрана во время удержания. Убедиться, что старое видео не возобновляется и позиция сохраняется.
8. PiP, background/foreground, блокировка экрана и звонок; совместный просмотр остаётся на 1×.
9. Папки: обе темы, пустая папка, 1/9/100+ элементов, длинные названия, клавиатура в landscape, прокрутка, reorder/удаление, подтверждение удаления папки, смена аккаунта и поиск добавления. Данные коллекций должны сохраниться.
10. Реальные Kodik/Anilibria/manifest-потоки и fallback: доступность, выбор озвучки, скорость, субтитры, прогресс. Шесть opt-in live-тестов оставлены для окружения с `ANIVIBE_LIVE_TESTS=1`.

### Установка

1. Распаковать архив в новую папку и сравнить с рабочим репозиторием. Сохранить backup и локальный `Config/Secrets.xcconfig`; `.git`, `.env` и секреты не заменять.
2. Можно использовать существующий `UPDATE_WINDOWS.cmd`: он переносит управляемые каталоги в backup. **Он не управляет корневым `Features/`.** Если там остались именно прежние два дубля и нет ваших правок, после просмотра diff отдельно выполнить `git rm -r Features`. Не удалять собственные новые файлы без переноса.
3. Не применять старые `*.patch` из прежних обновлений поверх новой версии: это исторические артефакты, не установщик v4.
4. Проверить `git status` / `git diff`, выполнить CI, только затем коммитить и выпускать. Новых миграций для этого обновления не требуется.
