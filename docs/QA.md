# Проверки и ручной чек-лист

## Выполнено в этой доработке

Среда: Amazon Linux 2023 x86_64, официальный Swift 5.10.1 Amazon Linux 2 toolchain, PostgreSQL 15.18. У Linux SDK потребовался callback-мост URLSession с отменой; эта ветка не меняет Apple URLSession.data(for:).

```bash
ANIVIBE_LIVE_TESTS=1 swift test --jobs 4 --package-path Packages/AnivibeCore
```

**128 тестов, 0 ошибок, 0 пропусков.** Финальный журнал: `qa-results/swift-final.txt`.

Покрыты старые модели/каталог/провайдеры/синхронизация и новые сценарии:

- реальная fixture Steel Ball Run: AniList 3 и источник 4 без выдуманного offset;
- specials/сезон 0, пропуски и одинаковые названия, отдельные идентификаторы;
- неоднозначное сопоставление возвращает отсутствие совпадения;
- длительно открытая панель, блокирование скрытия, новый таймер после закрытия;
- отдельный прогресс каталога/источника, сериализация и sync DTO;
- старые JSON без новых полей;
- смена аккаунта, гостевой файл и запоздалые player/sync-события;
- поздний refresh не отменяет logout;
- tombstones истории, сохранение и защита от восстановления старой строкой;
- пагинация 501 строки;
- русский источник недоступен → оригинал остаётся доступен;
- отказ обоих источников → ошибка, не ложное «ничего не найдено»;
- кэш, русский текст, aliases/транслитерация/опечатки;
- сохранение перестановки и защита от неверного IndexSet;
- серверная проверка email-кода и PKCE code exchange на mock-транспорте.

Живые тесты: AniList поиск/фильтры/детали/home/genres, реальные MAL-сопоставления AniLiberty, Apple/Blender HLS, AniList+Shikimori русское название и запросы «Слизь», «ТенСура», Tensura. Проверка Kodik metadata выполнена отдельно; видеопоток Kodik фактически не воспроизводился.
