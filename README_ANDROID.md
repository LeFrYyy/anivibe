# Anivibe для Android — Нативный порт

Полноценный нативный порт приложения **Anivibe** с iOS на платформу **Android**, расположенный в папке `android/`.

Проект реализован на современном стеке: **Kotlin + Jetpack Compose + Media3/ExoPlayer + Room + Supabase**.

Подробную документацию по структуре, запуску и миграциям смотрите в [`android/README_ANDROID.md`](android/README_ANDROID.md).

### 🚀 Быстрый старт
Откройте папку `C:\Users\ninaa\Downloads\Anivibe\android` в **Android Studio** и запустите на телефоне, планшете или Android TV!
