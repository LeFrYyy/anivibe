# Anivibe — обновление профиля и оформления

> Это описание первого этапа. Актуальные изменения аватаров, друзей, приватности и синхронизации папок описаны в `SOCIAL_UPDATE_RU.md`.

## Что сделано

- Профиль перестроен по иерархии присланного референса: центральный аватар 112 pt, имя, username, описание, видимость и кнопка редактирования.
- Добавлены карточки избранного, истории серий, коллекций и друзей. Коллекции открывают главную с существующими папками, друзья — поиск и список друзей. Нет фиктивных комментариев, уровня или индикатора онлайн.
- Статистика содержит реальные количества тайтлов по статусам. Счётчики статусов считаются одним проходом без сортировки. Каждая строка открывает соответствующую библиотеку; переход не создаёт вложенный NavigationStack.
- Почта и ID находятся в раскрываемом приватном разделе. Выход требует подтверждения. Профиль предыдущего аккаунта не используется для отображения текущего аккаунта.
- Сохранены локальный режим, вход/регистрация, восстановление, Google OAuth, синхронизация, обработка ошибок и повторная загрузка.
- Редактор получил крупный аватар, видимую проверку полей по существующим правилам ProfileDraft и защиту закрытия жестом во время сохранения/подготовки фото.
- Публичный профиль использует тот же блок идентичности без раскрытия почты, библиотеки или истории.
- Общие радиусы постеров/панелей, размеры бейджей и формы приведены к мягкому iOS-подобному оформлению. Панели профиля используют regularMaterial с непрозрачной заменой при Reduce Transparency.
- Учитывается Reduce Motion для появления постеров и splash. Кнопки статусов и палитры имеют области нажатия не меньше 44 pt. Стандартный контраст текста на акцентной кнопке учитывает светлую/тёмную тему.

## Оптимизация изображений

- Одновременные запросы одного URL используют общую задачу. Отмена одной ячейки не отменяет запрос других ячеек.
- Декодированные изображения имеют бюджет NSCache 96 МБ и предел 160 записей. Это лимит кэша, а не гарантия общей памяти приложения.
- Постеры декодируются через ImageIO вне главного потока, с максимальной стороной 1600 px. Сверхбольшие исходники не хранятся в полном разрешении. Декодированные ответы больше 40 МБ отклоняются; это не лимит сетевой загрузки.
- HTTP disk cache сохранён. Подписанные ссылки на аватары и их авторизация не менялись.
- PosterImage очищает изображение при nil URL и проверяет отмену/актуальность URL до публикации результата.
- Защита прогресс-бара от NaN/бесконечности.

Измерение FPS, пиков памяти и времени загрузки на устройстве не проводилось. Это конкретные изменения в реализации, не обещание измеренного ускорения всего приложения. Каталог, плеер, backend и миграции не переписывались.

## Версии iOS

«Под iOS 27» трактуется как эстетическое направление, не как заявленная поддержка неизвестного SDK или точное соответствие дизайну ОС. Deployment target 17.0 сохранён. Не добавлены недоступные API будущих версий; материалы и стандартная TabView используют возможности SDK сборки.

## Проверки здесь

- `python3 scripts/check_project.py` — успешно.
- `python3 scripts/test_build_scripts.py` — 8 тестов успешно.
- HTML-эскизы проверены визуально на ширине 390 и 760 px; светлый и тёмный мобильные варианты.
- Новые Swift-файлы не добавлялись: существующий Xcode project сохраняет регистрации исходников.

Нет Swift/Xcode, UIKit runtime и iOS Simulator в среде выполнения. Swift-компиляция, AnivibeCore tests, серверные тесты и проверка нативного UI здесь НЕ запускались. HTML-превью — статичный концепт с примерными данными, не снимок нативного экрана. Превью не копирует системную tab bar, вид которой определяется SDK.

## Как проверить и собрать

1. Откройте `Anivibe.xcodeproj` в Xcode. Секреты и подпись задаются по исходному README, никаких новых backend-настроек для редизайна не нужно.
2. Выполните сборку и тесты на macOS либо запустите существующий workflow `.github/workflows/ios.yml`. Зелёный CI ещё не заменяет UI-проверку на устройстве.
3. Проверьте профиль: локальный режим; гость с настроенным backend; успешный вход; загрузка/ошибка профиля; пустая/наполненная библиотека; редактирование; смена аккаунта; подтверждение выхода.
4. Проверьте переходы статистики, сохранение аватара и приватность, светлую/тёмную тему, свой акцент/фон, Dynamic Type, VoiceOver, Reduce Motion и Reduce Transparency на узком iPhone и iPad.
5. Для измерения оптимизаций сравните Allocations, Time Profiler и Network в Instruments на одной и той же подборке до/после.

Архив содержит исходники, а не собранную IPA.
